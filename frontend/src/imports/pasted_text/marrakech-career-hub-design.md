Design a complete high-fidelity DESKTOP APPLICATION UI/UX in Figma for a career platform called:

"Marrakech Career Hub"
Tagline: "Discover. Match. Apply."

IMPORTANT:
This is a DESKTOP APPLICATION, NOT a website.
Design it as a real production-ready desktop software interface, suitable for implementation with Python and PySide6.

PROJECT PURPOSE:
Marrakech Career Hub is an intelligent career platform designed for students and job seekers in Marrakech, Morocco.

The application contains a database of 208 cleaned companies in Marrakech and helps users:
- Discover companies by sector
- Search and filter companies
- Explore companies on an interactive map
- Save favorite companies
- Create a personal profile
- Match their skills and CV with companies using AI
- Chat with an AI career assistant
- Build and analyze CVs
- Track job and internship applications
- Generate personalized application emails
- Automate application workflows with n8n
- Send emails after explicit user confirmation

DESIGN DIRECTION:
Create a premium, elegant, modern, professional desktop application.

The visual identity should combine:
- Career platform
- Data analytics
- Artificial intelligence
- Professional recruitment
- Moroccan/Marrakech identity in a subtle way

Do NOT make it look like LinkedIn.
Do NOT copy existing platforms.
Create an original visual identity.
